# Crash Intelligence evidence

Files in this directory are evidence only when produced by an executed command against the recorded environment. Do not treat the benchmark design or an empty template as a result.

- `*-portable-tests.md` records local build, unit-test, coverage, and frontend checks.
- `benchmark-*.json` is generated by `scripts/crash-intelligence/verify.mjs` from a live Compose stack.
- `2026-08-08-compose-benchmark.md` summarizes the first passing 10,000-report run and links its raw capture.

A valid performance/recovery capture must include the generated project name, report count, p95 latencies, grouping percentage, duplicate-effect count, and worker recovery time. Preserve failed captures as failures rather than deleting or relabeling them.
